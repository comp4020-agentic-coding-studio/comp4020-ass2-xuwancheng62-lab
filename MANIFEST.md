# Asset manifest — "Before It Stops" integration

Tracks every asset touched by the "Table for One" → "Before It Stops"
substitution and by the course's real-production requirements. This is
the single source of truth for asset status; `PLAN.md`'s "'Before It
Stops' asset plan" section states policy only and points here for
per-asset detail. See `PLAN.md`'s "Real production material, never
invented" rule (also in `CLAUDE.md`) for why a teaching-example row is
never presented as, or substituted for, real personal-project evidence.

Columns: **Asset ID** · **Week** · **Asset type** · **Teaching example or
owner-required evidence** · **Teaching purpose** · **Producer** ·
**Integrator** · **Dependencies** · **Acceptance criteria** · **Status**
(`NOT STARTED`, `BRIEF READY`, `GENERATING`, `QA PASSED`, `INTEGRATED`,
`OWNER REQUIRED`, `BLOCKED`) · **File path or destination** · **Notes**.
The `OWNER REQUIRED` status and "owner-required evidence" column value
are retained vocabulary only — no row currently uses them; see the
2026-09-13 revision history entry below.
